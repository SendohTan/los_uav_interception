# 三架无人机近距离物流信息交接

本项目研究这样一个场景：一架物流无人机沿未知航迹飞向交接区，三架接收机尝试接近它。接收机根据相机测得的相对视线闭环飞行。仿真中，任一接收机进入物流机中心 **0.6 m** 范围即满足距离判据。真实信息交接还需验证数据链是否完成传输和确认。

当前实验以 **60 Hz** 为基准。我们比较三架接收机同时起飞、在空中协调接近，以及按顺序起飞、各自接近这两类方案。每组用同一批 **180 个场景**，覆盖六类物流机航迹。

## 1. 主要结果

| 方案 | 成功 | 振荡 | 第 2 / 第 3 架直接可视率 |
| --- | ---: | ---: | ---: |
| 顺次出发，起点间距 2 m，0/6/12 s，不展开 | **157/180（87.22%）** | **0/180（0.00%）** | 76.43% / 71.85% |
| 顺次出发，起点间距 5 m，0/6/12 s，不展开 | 155/180（86.11%） | 2/180（1.11%） | 75.59% / 72.82% |
| 顺次出发，起点间距 5 m，0/4/8 s，不展开 | 145/180（80.56%） | 0/180（0.00%） | 72.86% / 72.70% |
| 同时出发，6 s 展开＋走廊，单机参数已对齐 | 118/180（65.56%） | 17/180（9.44%） | — |
| 同时出发，错峰主备，单机参数已对齐 | 117/180（65.00%） | 16/180（8.89%） | — |

**顺次出发且不在空中额外展开，在这批仿真里取得了更高的交接成功率和更低的振荡率。** 起点间距指中间机到任一侧机的距离。顺次出发由中间机先起飞，其他两架按表中时刻依次加入。展开指侧机起飞后相对自身起点的额外横向移动。完整报告列出 15 组顺次出发结果、同时出发参数对齐、取消友机近接终止的复跑和频率消融。[完整实验报告](docs/logistics_rendezvous_60hz/REPORT.md)

后发机需要持续识别物流机，并将它与先发机区分开。仿真假定目标身份关联正确，统计的是视野、丢检和几何遮挡。以 2 m 起点、0/6/12 s 不展开为例，第 3 架在原本几何可观测的帧里，有 **5.29%** 被先发机挡住。识别能减少误跟，物流机完全被挡时仍会丢失这一帧。实机评估还应记录身份切换、连续失视和实际交接确认。

## 2. 观测与控制

LOS（Line of Sight）是接收机到物流机的视线方向。相机给出方位角、仰角和估计距离，控制器用最近一段带噪、带延迟的视线历史估计 LOS 角速度。短时前视将当前视线沿估计的变化方向提前，速度跟踪项和比例导航项共同生成加速度指令。指令经平滑、变化率约束和执行器模型后作用于飞机。失视时已有指令衰减，恢复有效观测后重新闭环。

同时起飞的两个对照都先展开 6 s。走廊方案为各机安排不同的接近通道，减少航迹重合。错峰主备也同时起飞，但在空中按主备角色安排接近先后。顺次出发直接错开发射时刻，减少需要同步机动的阶段。统一单机参数后，各组仍保留各自的起飞和空中协调规则。

| 项目 | 60 Hz 主实验条件 |
| --- | --- |
| 物理、相机和 LOS | 同步更新，周期 **1/60 s ≈ 16.67 ms** |
| 图像 / 控制指令时延 | 各 **100 ms**，各对应 6 个更新周期 |
| 视线角误差 | 世界方位角误差为 0。世界仰角逐帧加入标准差 **0.5°** 的截断高斯噪声，范围 **±1.5°** |
| 相机与测距 | 名义视场 **24° × 16°**，垂直方向采用理想跟踪。像素测距系数 **1200 pixel·m**，单帧独立随机丢检 **1%** |
| 友机通信 | 报文周期 **200 ms**，传输延迟 **200 ms** |
| 指令与执行器 | 最终垂直指令低通 **0.3 s**，加速度一阶响应 **0.2 s**。速度、加速度和 jerk 受机型约束 |
| 场景 | 直线、余弦、圆弧、随机、多正弦、B 样条。主对照每类 30 回合，回合最长 **100 s** |

60 Hz 每秒给出更多指令，同向更新仍只算同一次修正。频率对照里，直接飞行沿用旧离散设置时，振荡升到 **59/60**。重新按相同的物理时间尺度设定角速度历史、滤波与速度追逐力度后，振荡降到 **1/60**，成功为 **49/60**。这批仿真采用独立逐帧噪声，增加采样频率也改变了单位时间内得到的噪声样本数。原 10 Hz 直接飞行对照为 **13/60** 振荡和 **52/60** 成功。[频率对照与拆分结果](docs/logistics_rendezvous_60hz/REPORT.md#频率对照)

## 3. 指标口径

| 指标 | 判定方式 |
| --- | --- |
| 交接成功 | 用相邻状态之间的连续相对线段计算最近距离。任一接收机满足 **0.6 m** 几何判据，并满足 **5 m** 前的高度约束。物流机先到达距原点 **10 m** 的终止范围计失败 |
| 振荡 | 每架机去掉最初 **2 s**，剩余有效记录至少 **4 s**。同时满足归一化指令最大轴换向频率 ≥ **0.4 Hz**（死区 **±0.08**）、实际加速度主要轴 **0.2–2.5 Hz** 动态能量占比 ≥ **25%**、实际加速度最大轴峰峰值 ≥ **0.8 m/s²**。任一架满足即记该回合振荡 |
| 直接可视率 | 后发机相机检出物流机的帧数 / 该机起飞以后采样的帧数 |
| 先发机遮挡率 | 被更早起飞的友机遮挡的帧数 / 该机原本几何可观测的帧数，分母与直接可视率不同 |
| 友机近接 | 仿真另外统计近接和终止。正式对照中，空中评分段采用 **2 m** 规则，双机均进入物流机 **5 m** 范围时豁免。地面待发和同步展开期单独记录 |

jerk RMS 用于描述实际加速度变化的剧烈程度。振荡以原始采样率判定，同时保留从同一段记录抽取到 10 Hz 的复算结果。实际飞行中的间隔、下洗和场地安全需要单独验证，尤其是 **2 m 起点** 的方案。[统计细节和部署局限](docs/logistics_rendezvous_60hz/REPORT.md)

## 4. 运行与复算

克隆后用 Python 3.9 或更新版本。以下三机结果汇总脚本使用标准库，可将输出重定向保存为 CSV。`--cohort added120` 可以单独查看追加的 120 回合。

```bash
git clone https://github.com/SendohTan/los_uav_interception.git
cd los_uav_interception
python examples/summarize_logistics_results.py sequential_matrix
python examples/summarize_logistics_results.py sequential_matrix --cohort added120
python examples/summarize_logistics_results.py synchronous
python examples/summarize_logistics_results.py rate_regression
```

单机离线振荡诊断使用时间戳、三个轴的归一化指令和实测加速度。安装包后，复算命令如下。[单机 CSV 格式与输出说明](docs/SINGLE_OSCILLATION_AUDIT.md) · [单机合成样本结果](docs/STABILITY_60HZ_RESULTS.md)

```bash
python -m pip install -e .
python -m los_uav_interception.single_oscillation_audit trajectory.csv
```
