# LOS UAV Interception

后续仿真以 **60 Hz** 为基准，物理、相机和 LOS 同步更新。图像延迟和指令延迟各保留 **100 ms**。

## 60 Hz 对照结果

三机直接飞行场景，每组 60 个配对回合。成功率按原实验的交接判定统计。

| 仿真设置 | 交接成功 | 振荡回合 |
| --- | ---: | ---: |
| 10 Hz 基线 | 52/60（86.7%） | 13/60（21.7%） |
| 60 Hz 沿用原离散设置 | 55/60（91.7%） | 59/60（98.3%） |
| **60 Hz 保持原实际时间尺度** | **49/60（81.7%）** | **1/60（1.7%）** |

保持原时间尺度的 60 Hz 组比 10 Hz 基线少 12 个振荡回合，同时少 3 个成功回合。同一批 60 Hz 日志抽取到 10 Hz 后，仍是 1/60 个振荡回合。[完整三机对照和单机振荡验证](docs/STABILITY_60HZ_RESULTS.md)

## 为什么更新更频繁，实际换向反而更少？

飞机连续向左修正 0.3 s，10 Hz 约发 3 次向左指令，60 Hz 约发 18 次，两者的换向次数都是零。指令越过死区并进入反向才算一次换向。

沿用原离散设置时，估计窗口在真实时间上变短，每次更新的追逐修正也更强，短时观测波动更容易触发反向。保持原时间尺度后，同样时长内可以用更多观测点估计角速度，控制指令也更平顺。这次实验同时改变了采样、滤波和增益，尚未测出各项对振荡率的独立贡献。

## 仓库里的 60 Hz 内容

单机已完成 60 份合成日志的离线验证，原始 60 Hz 和抽取后的 10 Hz 在所有样本上判定一致。单机尚无 60 Hz 闭环交接成功率。三机结果来自主项目仿真，本仓库的闭环仿真代码仍为 v0.4.1。
