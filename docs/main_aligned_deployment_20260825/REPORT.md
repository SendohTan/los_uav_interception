# 主项目部署口径对齐与正式复测

日期：2026-08-25  
版本：v0.4.0  
正式随机种子基准：`2026082591`

## 1. 对齐范围

本版本将独立仓库的部署仿真和评价口径与 `mappo_uav_project` 当前正式配置统一：

- 仿真步长 `0.1 s`，最长 `1000` 步，命中阈值 `0.6 m`；
- 命中采用相邻仿真状态之间的连续线段最近距离，命中函数 F 仅记录诊断值；
- A 型拦截机、C 型靶机及其水平/垂直速度、加速度和 jerk 限制；
- 30 Hz 相机最近帧，`1/30 s` 观测延迟，`24°×16°` FOV，1% 丢检；
- `0.5°` 方位角/高度角截断高斯误差，截断范围为 `±3σ`；
- `C=1200 pixel·m`、`±1 pixel` 的离散测距模型；
- 延迟时刻的精确 LOS 角速度输入；
- 1 帧控制延迟和 `0.2 s` 加速度执行一阶响应；
- Stable LOS 参数：`N=4.0`、追逐增益 `0.04`、提前时间 `3 s`、LOS 率软阈值 `0.002 rad/s`、期望速度滤波 `0.25 s`、速度变化率上限 `4 m/s²`、导引加速度滤波 `0.12 s`；
- line、cosine、arc、random、multi-sine、B 样条六类动力学受限靶机轨迹。

三机角色分配未修改。独立仓库仍为三架独立 LOS 拦截机，初始位置存在小范围空间偏置，初始速度比例为 `0.75/0.85/0.95`，导航常数为基础值的 `0.9/1.0/1.1` 倍。该结构与主项目的一架观测机加两架拦截机结构不同，因此多机结果用于本仓库内部评价，不用于直接替代主项目协同结果。

## 2. 部署模型修改

### 2.1 相机姿态与 FOV

原 FOV 使用瞬时速度方向近似相机光轴，飞机转向时光轴会立即同步。新模型按主项目实现计算机体姿态：

- 航向角目标由水平速度方向确定；
- 俯仰角目标由垂直速度和水平速度确定；
- 滚转角目标由侧向加速度与重力加速度的比值确定；
- 航向、俯仰和滚转以 `0.25 s` 时间常数进行一阶响应；
- 相机坐标系由机体姿态与云台俯仰安装角共同得到；
- LOS 投影到相机前、右、下三轴后判定水平和垂直视场边界。

该处理保留了机体转弯、侧滑和姿态响应对目标可见性的影响，避免瞬时速度光轴带来的过理想跟踪。

### 2.2 靶机轨迹

- 初始距离为 `300–500 m`，初始高度角为 `-45°–45°`；
- 靶机初始速度比例由固定 `0.82` 改为每回合随机 `0.55–0.95`；
- random 使用总体指向任务区的平滑随机游走航点，末段恢复指向原点；
- B 样条改为 SciPy 三次插值样条，通过随机航点而非把随机值作为控制多边形；
- multi-sine 和 B 样条在航程进度达到 50% 后进入受限末段收敛与制动；
- 所有指令继续经过 C 型靶机的速度、加速度和 jerk 限制。

### 2.3 控制日志

逐帧轨迹 CSV 新增：

- Stable LOS 期望速度；
- N/E/D 三轴归一化控制动作；
- 控制延迟、执行器响应、限幅和 jerk 限制之后的实际执行加速度。

这些信号用于复现主项目振荡判据，并支持 HIL 和试飞日志对照。

## 3. 指标定义

### 3.1 拦截指标

若任一拦截机与靶机在相邻仿真状态之间的连续线段最近距离小于 `0.6 m`，该回合记为成功。命中函数 F 的相对速度、方位角、高度角和距离分量独立记录，不参与成功判定。

### 3.2 振荡指标

每回合去除前 `2 s` 暖机数据。对每架拦截机执行以下计算：

1. 对归一化三轴动作应用 `0.08` 死区，统计最大轴符号换向频率；
2. 选择实际执行加速度 RMS 最大的轴，去趋势后计算频谱；
3. 统计 `0.2–2.5 Hz` 频带动态能量占比；
4. 统计三轴实际执行加速度最大峰峰值；
5. 同时满足有效时长不少于 `4 s`、换向频率不低于 `0.4 Hz`、频带能量占比不低于 `0.25`、峰峰值不低于 `0.8 m/s²` 时判定该机振荡；
6. 多机回合中任一拦截机满足条件即判定该回合振荡。

jerk RMS 使用实际执行加速度差分计算，不再使用导引指令或速度误差替代。

三机总体命中率比单机高 `1.67` 个百分点。提升主要来自 random、multi-sine 和 B 样条，其中 B 样条提高 `7` 个百分点。line 已达到饱和，cosine 和 arc 在本批随机种子上没有净提升。三架飞机采用相近的独立 LOS 控制并从相邻位置起飞，失败相关性仍然较高，因此数量增加没有形成接近三倍的独立命中机会。

两种场景的换向频率均显著低于 `0.4 Hz` 判据阈值，正式样本中未出现同时满足全部振荡条件的回合。该结论适用于当前点质量动力学和执行器一阶响应模型，实机仍需使用同一日志字段在 HIL 和限速试飞中复核。

## 7. 工程边界

当前模型可用于导引层算法、传感器误差和指令平滑性验证。实际飞行部署仍需要姿态内环、飞控接口时序、真实电机/桨动力学、通信延迟抖动、风扰、GPS/惯导误差、坐标系标定、故障保护、地理围栏和安全员接管。后续 HIL 与试飞应直接记录本版本定义的归一化动作和实际执行加速度，以保持仿真与实机评价口径一致。
